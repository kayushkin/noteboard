# @kayushkin/noteboard-types

TypeScript types for noteboard's wire format, generated from the Go types in
`model/` with [tygo](https://github.com/gzuidhof/tygo). The Go package is the
source of truth; do not edit `model.ts` by hand. Regenerate with
`./generate-ts.sh` at the repo root.

Source-only for now: install with `file:../noteboard/ts`.
